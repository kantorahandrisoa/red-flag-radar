# Test CSV files

Generated by `make test-csvs` (`scripts/make_test_csvs.py`); checked by `pytest` and by
`python scripts/check_test_csvs.py --base-url http://localhost` against a running server.
Valid files carry two extra columns the API ignores: `expected` and `case`.

| File | What it tests | Expected |
|---|---|---|
| `01_all_cases.csv` | 19 matching cases: exact copy with NPI, typos, initial, swapped names, nickname, compound surname, titles/suffixes, accents, moved state, FDA name-only, innocent namesakes, different NPI, common name, invented name | each row's `expected` zone |
| `02_full_name_only.csv` | single `full_name` column, "Last, First M" and "Dr First Last MD" | accepted, per-row zones |
| `03_names_only.csv` | only first and last names | accepted |
| `04_messy_headers.csv` | headers in another order, other case, with spaces; unknown columns | accepted, extras ignored |
| `05_utf8_bom_accents.csv` | UTF-8 with BOM, accented names | accepted |
| `06_missing_values.csv` | blank fields, missing first/last name, missing id | accepted, ids `ROW-xxxx` filled in |
| `07_npi_formats.csv` | NPI with dashes, too short, all zeros, different | accepted, invalid NPIs ignored |
| `08_quotes_and_punctuation.csv` | apostrophes, hyphens, commas in quoted fields, extra spaces | accepted |
| `09_csv_injection.csv` | cells starting with `= + - @` | accepted; CSV export neutralizes them |
| `10_limit_5000_rows.csv` | the 5,000-row maximum | accepted in under 60 s |
| `err_01_no_name_columns.csv` | no name columns | 422 |
